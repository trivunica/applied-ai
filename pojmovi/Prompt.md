# Prompt (Prompt)

## Definicija
Prompt je vrsta [[Ulaz|ulaza]] koji korisnik ili drugi sistem daje [[Jezički model|jezičkom modelu]] kako bi usmerio njegovo ponašanje i generisanje odgovora.

## Primer
Opis dela i mašine poslat modelu za pravljenje nacrta radne instrukcije u fabrici [[Orion Precizni Delovi]].

## Napomene
Može sadržati instrukcije, pitanja, primere ili dodatne informacije i predstavlja deo [[Kontekst modela|konteksta modela]]. Precizniji prompt smanjuje, ali ne uklanja u potpunosti rizik od [[Halucinacija|halucinacija]].
