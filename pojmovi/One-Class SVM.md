# One-Class SVM (One-Class Support Vector Machine)

## Definicija
Metod [[Detekcija anomalija|detekcije anomalija]] koji se uči samo na primercima [[Normalno ponašanje|normalnog ponašanja]] i određuje granicu koja ih obuhvata, a primerke van granice smatra anomalijama.

## Primer
Model se uči samo na zapisima o redovnom radu klinike. Zapis o noćnom masovnom preuzimanju kartona pada izvan naučene granice i prijavljuje se.
