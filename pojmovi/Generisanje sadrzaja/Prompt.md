# Prompt (Prompt)

## Definicija
Instrukcija ili ulazni tekst kojim se usmerava generisanje sadržaja. Može sadržati zadatak, ograničenja, primere i željeni format izlaza.

## Primer
„Napiši sažetak ovog članka u tri rečenice za učenike osmog razreda.“

## Napomene
Precizniji prompt smanjuje, ali ne uklanja rizik od [[Halucinacija|halucinacija]]. Prompt je deo [[Kontekst|konteksta]]. U učenju zasnovanom na promptu (prompt-based learning) ulaz se pomoću šablona pretvara u tekstualni prompt sa nepopunjenim mestima koja [[Jezički model|jezički model]] popunjava (Liu i sar., 2023).
