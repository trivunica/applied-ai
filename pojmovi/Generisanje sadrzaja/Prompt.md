# Prompt (Prompt)

## Definicija
Prompt je ulaz koji korisnik ili drugi sistem daje [[Jezički model|jezičkom modelu]] kako bi usmerio njegovo ponašanje i generisanje odgovora. Može sadržati instrukcije, pitanja, primere ili dodatne informacije i predstavlja deo [[Kontekst modela|konteksta modela]].

## Primer
„Napiši sažetak ovog članka u tri rečenice za učenike osmog razreda.“

## Napomene
Precizniji prompt smanjuje, ali ne uklanja rizik od [[Halucinacija|halucinacija]].
